### 📖 Sobre este proyecto
Este sitio web fue desarrollado como un detalle especial para **Sarahi** y nuestro bebé **Víctor Gael** en sus primeros 2 meses. Cuenta con:
* 📱 **Diseño 100% Responsivo:** Optimizado para celulares, tablets y laptops.
* 🖼️ **Visor Modal:** Galería interactiva para ampliar cada foto.
* ⏳ **Línea del Tiempo Cronológica:** Registro de cada etapa desde su nacimiento hasta hoy.

Una página web interactiva y responsiva creada como un tributo especial para celebrar los primeros 3 meses de vida de nuestro pequeño gran "Pugcito", Víctor Gael. 

## 🌟 Características del Proyecto
* **Línea de tiempo interactiva:** Documenta la historia, retos y victorias de Gael desde su nacimiento hasta hoy.
* **Galería Fotográfica:** Imágenes de la familia y el proceso de recuperación de nuestro guerrero.
* **Reproductor de Audio Integrado:** Canción de fondo (*En Mi Corazón Vivirás* de Phil Collins) optimizada para navegadores web y dispositivos móviles.
* **Diseño Responsivo (Mobile-First):** Interfaz adaptada con CSS puro para que la familia pueda disfrutar la página perfectamente desde cualquier celular o computadora.
